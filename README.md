# Pixel Plumber

An original pipes-and-coins platformer, inspired by the classic genre but built from scratch: procedurally drawn on `<canvas>`, no borrowed art or music (all sound effects are synthesized with the Web Audio API).

## Play

Open [`index.html`](index.html) in any modern browser, or enable GitHub Pages on this repo to play it online.

## Controls

- **Move:** Arrow keys or A / D
- **Jump:** Space, Up, or W — press again in mid-air for a **double jump**
- Touch controls are built in for mobile

## Features

- Full physics-based platforming (gravity, momentum, friction, coyote-free precise jumps)
- Double jump
- Coins, pits, floating brick platforms, pipes, patrolling enemies you can stomp
- Parallax background (sun, mountains, clouds, hills), particle effects (dust, sparkles, confetti), camera shake, and squash-and-stretch animation
- Lives, score, countdown timer, win/lose screens

Single self-contained HTML file — no build step, no dependencies.
